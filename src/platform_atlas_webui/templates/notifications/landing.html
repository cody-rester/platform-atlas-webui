What is this? A shared password you choose. Atlas uses it to sign every outgoing webhook so your receiver can prove the request really came from Atlas (and wasn't tampered with in transit). Pick a long random string — click Generate to make a strong one — and configure the same value on your receiver. If you don't need signing (e.g. internal-only, behind a firewall) leave it blank.
How does the receiver verify it?
Atlas adds X-Atlas-Signature: sha256=<hex> to every webhook, where <hex> is HMAC-SHA256(secret, raw_body). Your receiver should:
  1. Read the raw request body (don't parse JSON first — bytes must match).
  2. Compute HMAC-SHA256(secret, raw_body) using the same secret.
  3. Compare hex digests in constant time against the header value.
  4. Reject the request if they don't match.
Example (Python): hmac.compare_digest(received, hmac.new(secret.encode(), body, hashlib.sha256).hexdigest())
